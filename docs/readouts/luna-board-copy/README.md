# Board.copy structural clone review

These are isolated public-code measurements; neither prototype was promoted to a production strength source.

The pinned Catanatron contract keeps maritime/bank/port trades enabled. Player-to-player `OFFER_TRADE` is not generated by `generate_playable_actions`, and the bridge entrant is constructed with `max_trades=0`. The recorded games had no `OFFER_TRADE`, `ACCEPT_TRADE`, or `CONFIRM_TRADE` actions. `ActionRecord` is `(action, result)`, so trade inspection uses `record.action.action_type`.

The 8-pair instrumented run used seeds `290000000..007` and matched winners, scores, action traces, spectra, fallback arrays, and board shapes. Its full artifact is `board-copy-8pair-instrumented-result.json` (SHA256 `0180eb8e7b81c38989912549aad5aa59a0153214be857c7d720604063582c04a`). The harness is archived beside it (SHA256 `a4aa07b72c12654e66e3e3670e14ec1cbb9c79b276484d5d6cfcdca08c831dc0`). Because it captured every minimax spectrum and repr trace, its approximately 16% reduction is instrumented timing.

The clean run used predetermined seeds `291000000..003`, with no spectrum or feature tracing, and also matched all outcomes and traces. Baseline totals were 128.641485 wall seconds / 127.682851 CPU seconds; clone totals were 114.337235 / 113.160233, ratios 0.888805 / 0.886260. This is an 11.1% wall reduction over four pairs only, not a production speed claim. The clean result SHA256 is `96ca39ab1453c061a14f2c7f1fbb6047a217c9f4cb7168377b4b423dfe925131`; its harness SHA256 is `b37235d24128d2e223dde5b8d6b279ab16ff77d9f43aa2c88c70a069061de9be`.

The native AB2 deadline remained 20 seconds. Catanatron exposes no timeout-hit counter, so timeout incidence is unavailable; it was not inferred as zero. Fallback arrays were `[0, None, None, None]`: the bridge counter was zero, while native AB players expose no fallback telemetry.

The first three clean-container attempts are excluded launch failures and produced no games: v1 and v2 lost base64 quoting through the remote shell; v3 fixed quoting but omitted `PYTHONPATH=/study/src` and failed with `ModuleNotFoundError: hexset`. Only named v4 (`luna-board-copy-clean-291000-v4`) produced the clean artifact.
