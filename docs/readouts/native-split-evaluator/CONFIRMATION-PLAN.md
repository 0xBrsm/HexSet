# Fresh split-evaluator confirmation

The 128-game/cell exploratory screen selected N:T: 34 wins, versus N:N 19,
T:N 14 and T:T 23. The paired N:T minus N:N interval excludes zero, but
N:T minus T:T remains uncertain (+8.59pp, exploratory 95% -1.38 to +18.56pp).
Confirm only N:T versus T:T, with three fixed T:T opponents, on fresh seed
719000000, indices 0–511, independent boards and balanced candidate seats.
All four seats trade at floor zero. Same profiles, source, search settings,
wrapper, event census and information model as the screen. Thirty workers;
start after the census audit finishes, so only one pool runs at a time.

Complete all 512 games per candidate; no optional stopping or reselection.
Primary outcome is the paired candidate-win difference N:T minus T:T across
shared board indices, with a two-sided 95% normal interval using sample SD of
per-board differences. A strictly positive lower bound confirms improvement
in this population. Also report individual Wilson intervals and trade counts.
No sliding weights, threshold changes or profile defaults are introduced.
