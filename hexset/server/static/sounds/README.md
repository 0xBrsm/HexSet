# Sounds

The page's sound effects, played only once a browser turns sound on. Every file
here is by Kenney (https://kenney.nl), released under Creative Commons Zero
(CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/), unchanged and
under its own name:

- the card, chip and dice clips, from *Casino Audio* 1.1
  (https://kenney.nl/assets/casino-audio);
- `jingles_PIZZI*.ogg`, from *Music Jingles* (https://kenney.nl/assets/music-jingles).
